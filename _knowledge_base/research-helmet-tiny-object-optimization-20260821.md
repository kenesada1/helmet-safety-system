# 安全帽微小目标优化方向调研笔记

调研日期：2026-08-21

调研目标：结合项目 E5-A 负结果，调研微小目标检测中比整图重复重采样更合理的训练增强、模型结构与损失/样本分配方向，并形成可验证的下一步实验优先级。

## 关键问题

1. 为什么重复整张困难图片会提高微小目标召回率却同时增加误检、损伤总体指标？
2. 温和的目标中心裁剪、目标级复制、P2 高分辨率检测头分别有什么实证依据和工程代价？
3. 在本项目 960 输入、6GB 显存和 E4 候选 C 基线下，下一轮应优先验证什么，如何控制变量？

## 项目证据

- E4：总体正确检出 9420、漏检 505、误检 951、综合指标 0.928262；微小目标正确检出 79、漏检 49、召回率 0.617188、综合指标 0.607692。
- 延长训练对照：总体综合指标 0.924357；微小目标正确检出 83、漏检 45、召回率 0.648438、综合指标 0.601449。
- E5-A：总体综合指标 0.921457；微小目标正确检出 86、漏检 42、召回率 0.671875、综合指标 0.593103。
- E5-A 相对延长训练对照：微小目标多正确检出 3 个，但多误检 11 个，微小目标综合指标下降 0.008346；总体少正确检出 37 个、多漏检 37 个、多误检 21 个。
- E5-A 的 1043 个额外位置有放回地集中抽取 161 张微小困难图片；训练23轮耗时16.504小时，对照30轮耗时5.984小时。

## 发现

### 第一轮：数据增强与微小框度量

- Kisantal 等人的微小目标增强论文并非只做整图过采样，而是把小目标复制粘贴到图中以增加“单图内的小目标实例数”；在其 COCO 实验中，小目标检测获得相对提升，但论文也明确指出这是用大目标质量换取小目标质量的权衡。该证据与本项目“整图重复提高微小召回、损伤总体指标”的现象一致，说明下一步若采用复制，应复制目标实例而不是继续高频重复整张图片。
- Ultralytics 当前内置 `copy_paste` 官方文档明确标为实例分割专用；本项目只有检测框标签，因此不能直接打开该参数并声称完成目标级复制。若做检测框级复制，需要独立实现并验证粘贴位置、遮挡、边界和全部标签转换。
- Scale Match 论文指出预训练/训练之间的目标尺度分布不匹配会损伤微小目标表征，支持“裁剪后应控制放大尺度分布，而不是把所有目标都放得很大”。
- 归一化高斯瓦瑟斯坦距离论文指出，交并比对微小框的少量像素偏移极敏感；该方法可作用于样本分配、损失和非极大值抑制，但官方实现基于较旧的 MMDetection/锚框检测器，迁移到当前 YOLO11 的任务对齐分配器属于高风险结构改造，不适合作为下一轮低成本首选。
- Ultralytics 社区中可见 P2 模型、裁剪训练与高分辨率输入被反复用于约 10～15 像素目标，但社区回答多为经验建议，不能替代本项目的严格对照实验。

### 第二轮：裁剪训练、P2 与训练目标

- SNIP/SNIPER 的核心不是无差别放大，而是在不同图像尺度或局部芯片上，仅让处于合适尺度区间的目标参与梯度；这支持本项目采用“带上下文的目标中心裁剪 + 尺度上限 + 原图混合”，并同时加入背景/负芯片控制误检，而不是把161张困难整图反复训练。
- Albumentations 官方提供能同步变换检测框的安全裁剪：`RandomSizedBBoxSafeCrop` 可保留全部框后缩放，`AtLeastOneBBoxRandomCrop` 可保证至少保留一个框。对本项目而言，通用安全随机裁剪可作为实现基础，但更合理的是以训练集微小目标为锚点的可审计裁剪，并明确处理裁剪边界框、最小可见比例和全部框坐标。
- Ultralytics 官方仓库存在 YOLOv8 P2 配置，检测输出为 P2/4、P3/8、P4/16、P5/32，说明 P2 是官方认可的结构变体；但当前项目使用 YOLO11，官方仓库没有对应的 YOLO11-P2 预训练权重，因此直接迁移意味着自定义结构、部分权重加载、额外显存和新的训练变量。
- 当前 Ultralytics 检测损失使用任务对齐分配器，将分类分数与定位质量组合选取正样本，并使用二元交叉熵分类损失。焦点损失确实针对密集检测中大量容易背景压过少量困难样本的问题，但 E5-A 的问题不仅是背景不平衡，还包含重复场景偏置；在没有先完成温和数据增强对照前修改损失，会同时改变样本分配/分类优化口径，难以归因。

### 阶段摘要（第3轮）

当前一手证据把优先级指向“尺度受控的训练裁剪/目标级增广”，而不是继续增加整图重复。P2 有明确结构依据，但工程成本和部署代价更高，适合在数据增强单变量之后验证。归一化瓦瑟斯坦距离、焦点损失或任务分配修改属于后续高风险研究分支，不宜与下一轮数据实验混合。

### 第四轮：重复集中度与成熟采样器

- 对本项目清单的直接审计显示：E5-A 的1043个额外位置只覆盖151张图，最高单图额外出现74次，前10张图占额外抽样31%；合并基础清单后，最高单图在6500条中出现75次。对照组额外抽样覆盖955张图，最高仅4次。这是比“总重复比例”更关键的失败证据：模型被少数固定背景和拍摄条件反复推动，微小召回增加但误检和总体退化符合场景记忆/分布偏移的表现。
- 被高频重复的图片中存在极密集标注：额外出现49次的 `001117.jpg` 有152个真实框，额外31次的 `PartB_01049.jpg` 有90个真实框。Ultralytics 任务对齐分配会按批次最大真实框数构建候选张量，因此密集图被反复采样很可能是 E5-A 每轮耗时显著高于对照的重要原因；这是根据本地清单和官方源码做出的推断，仍应通过逐批耗时统计验证。
- Detectron2 的官方重复因子采样器使用类别出现频率和平方根形式计算每图重复因子，并支持小数重复因子的随机取整；这种渐进式重复比按漏检数量线性加权温和。该方法为“平方根压缩权重 + 单图上限”提供成熟先例，但本项目只有两个类别，真正需要平衡的是尺寸/困难程度而非类别长尾，不能直接照抄类别公式。
- 在线困难样本挖掘论文强调从一张图内部的大量候选区域中选择困难区域，而不是反复输入整张图。这进一步支持把训练关注点转移到目标附近裁剪、困难负区域或损失级别，而不是继续整图重复。

### 第五轮：后续结构与稀疏高分辨率方向

- QueryDet 论文把小目标困难归因于下采样后特征消失、背景噪声污染、感受野不匹配以及微小框定位敏感；其解决方案是先低分辨率粗定位，再只在可能存在小目标的区域稀疏计算高分辨率特征。该思想与本项目滑窗结果高度相关：全图无条件切片带来大量背景误检和约5.6倍延迟，而“有查询引导的局部高分辨率”才是更合理的长期部署方向。但它不是当前 YOLO11 的低成本参数调整。
- RFLA 通过高斯感受野距离和分层标签分配改善微小目标正样本分配，在 AI-TOD 上报告明显提升；它与本项目14个轻微定位偏差漏检有理论对应。但官方实现基于 MMDetection，迁移到 YOLO11 任务对齐分配器需要重写训练损失和分配逻辑，应排在 P2 与裁剪增强之后。
- 目标级复制必须注意上下文、粘贴尺度和遮挡；Ultralytics 检测任务的内置 `copy_paste` 不生效是官方文档明确的任务边界，只有检测框时若直接复制矩形块，会连背景一起复制并产生边缘伪影。因此更适合作为“裁剪放大验证成功后的第二个数据实验”，且需要小概率、单图复制数量上限和困难负样本对照。
- 上下文驱动复制研究和后续工作都指出，随机粘贴会产生位置语义不合理、碰撞和局部外观不一致；本项目安全帽与人体头部具有强上下文关系，若没有实例掩膜，矩形框级复制尤其容易把原背景一起带入。因此目标级复制不应先于上下文裁剪；若后续实施，应优先复制“头部+安全帽上下文块”，而不是只复制一个几像素的帽子框。

## 最终综合结论

### 已确认的事实

1. E5-A 不是“完全没有学到微小目标”，而是用明显更差的样本效率换来少量微小目标召回：相对延长训练对照只多正确检出3个微小目标，却多出11个微小误检，微小目标综合指标和总体指标均下降。因此应作为负结果保留，不能替代 E4。
2. 失败关键不只是“重复”，而是重复高度集中：1043个额外训练位置只覆盖151张图，前10张占31%，单张最高额外出现74次。它同时重复目标、背景、相机视角和标注噪声，不能等同于有效增加微小目标多样性。
3. 公开方法较一致地支持三条原则：把训练关注点从整图移到目标/区域；控制放大后的尺度分布，避免训练与推理尺度失配；保留上下文并配入困难背景区域，防止召回提升伴随误检增加。
4. 本项目仅有检测框，Ultralytics 内置 Copy-Paste 不适用。没有实例掩膜时，直接复制几像素目标框会带入背景和边缘伪影，风险高于带上下文裁剪。
5. P2、RFLA、归一化瓦瑟斯坦距离和稀疏高分辨率检测均有文献依据，但会改结构、分配器或部署路径；它们不是下一轮最低风险的单变量。

### 推荐实验顺序

#### P0：冻结结论与训练前审计

- 将 E5-A 标记为负结果，保留权重、清单、配置和完整验证报告，不更新生产/项目基线。
- 核查最高频的20张图，重点记录密集标注、边界错误、模糊、遮挡与场景重复；按批次统计真实框数量与训练耗时，验证密集图是否造成明显计算放大。
- 后续结果同时报告总体、微小目标、安全帽微小目标、未佩戴安全帽微小目标；只有14个安全帽微小验证框，不能用1～2个框的变化直接下强结论。

#### P1：E5-B1 尺度受控的上下文裁剪训练（下一轮首选）

- 起点仍为 E4 最优权重，所有训练超参数和延长训练对照一致，唯一变化是新增训练样本的构造方式。
- 原始5457张训练图各保留一次；仍补足1043个位置，使每轮总量保持6500，保证与现有对照的更新步数可比。
- 不再复制整图。1043个新增位置只改为“微小目标中心、保留头部/人体上下文”的裁剪块；这一轮先不混入目标复制、困难背景挖掘或结构修改，以便能把结果归因于裁剪训练本身。
- 正裁剪来源扩展到全部278张含微小目标的训练图，而不是只用161张历史漏检图；单张原图最多生成4个裁剪，单个目标最多作为中心2次。安全帽微小目标至少各覆盖一次，但不允许少数图重新占满配额。
- 裁剪缩放以温和为原则：经完整训练增强流水线后，作为中心的目标等效边长主要落在12～20像素，硬上限约24像素；在训练前抽样可视化并统计至少1000个增强后批次，确认没有被 Mosaic 再次缩小或被过度放大。
- 裁剪时同步转换该区域内全部真实框；中心目标完整保留，其他框按预先固定的可见比例规则保留/删除，并生成自动越界、空框、类别和标签数量检查报告。
- 若单图最多4个、单目标最多2个的约束使合格裁剪不足1043个，剩余位置按延长训练对照的均匀抽样方式补齐，禁止放宽集中度上限。
- 保存为全新 E5-B1 目录，不覆盖 E4、延长训练对照或 E5-A。

#### P2：E5-B2 困难背景裁剪（按 E5-B1 结果决定）

- 如果 E5-B1 提高召回但误检仍明显增加，再单独把新增位置的15%～20%替换为 E4 在训练集产生误检的困难背景裁剪块；正负芯片并用与 SNIPER 的思想一致。
- 如果 E5-B1 连微小目标综合指标都没有提高，不应靠困难背景样本掩盖裁剪本身无效的事实，应停止该数据路线。

#### P3：E5-C 上下文目标级复制（仅在裁剪路线有正证据后）

- 复制“头部+目标上下文块”，不复制孤立的几像素帽子框；限制单图粘贴数量、粘贴概率和尺度范围，并做碰撞/遮挡检查。
- 这是独立单变量，不与 P2 检测头或损失修改同轮进行。若裁剪已无收益，不应直接假定目标复制会解决问题。

#### P4：P2 高分辨率检测头

- 数据路线验证后，再建立 YOLO11s-P2 独立结构实验。公共仓库有官方 YOLOv8-P2 配置，但没有可直接等价替换的 YOLO11-P2 预训练权重；因此应记录实际权重加载比例、新增头的随机初始化、显存、吞吐和延迟。
- 为隔离结构收益，先使用与延长训练对照相同的数据和训练设置；不要同时叠加 E5-B1。若结构单独有效，再测试二者组合。

#### P5：研究性方向

- 若剩余错误主要是几像素定位偏差，再评估 RFLA 或归一化瓦瑟斯坦距离；这需要修改 YOLO11 的任务分配/定位损失，优先级低于 P2。
- 若部署仍需要局部高分辨率，考虑 QueryDet 式“低分辨率粗筛 + 稀疏局部精检”，不要回到无条件全图滑窗。

### 预注册成功门槛

- 主比较对象是延长训练对照，不是 E5-A。
- 首要门槛：微小目标召回率与微小目标综合指标必须同时上升，避免再次出现“多检出几个、但误检涨得更多”。
- 总体综合指标相对延长训练对照下降不超过0.002；总体误检、微小误检和推理成本必须单列。
- 完整验证集固定使用候选C推理设置，禁止使用测试集调参。先做一个随机种子的筛选；只有越过门槛后，再补两个随机种子或图像级配对自助法置信区间，避免把128个微小目标、尤其14个安全帽微小目标中的偶然波动当成稳定提升。

### 最终建议

下一步不应继续“调大重采样权重”，也不应马上改损失。最值得投入的一轮是 E5-B1：保持训练步数和其他参数不变，把1043个集中重复的整图位置替换为有上限、尺度受控、保留上下文的目标中心裁剪。它直接针对 E5-A 暴露的场景重复集中问题，同时也是与现有论文证据及项目约束最一致、最容易做出清晰因果判断的实验；只有在召回提高而误检仍上升时，再用独立的 E5-B2 验证困难背景裁剪。
